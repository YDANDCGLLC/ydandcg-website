Contact form (Formspree):
1. Sign up at https://formspree.io and create a form.
2. Copy your Formspree endpoint (https://formspree.io/f/your-id).
3. Replace the form ACTION in index.html with your endpoint.
4. Optional: enable "Require validation" or spam protection in Formspree settings.
Fallback: if you don't replace the endpoint, the form will open the default mail client.

How to publish:
1. Upload the extracted files to the root of your GitHub repo.
2. Settings -> Pages -> Branch: main, Folder: / (root) -> Save
3. Wait a minute and open https://<username>.github.io/<repo>/
